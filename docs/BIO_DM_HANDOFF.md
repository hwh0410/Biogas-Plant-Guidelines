# 拜爾 Bio DM 第一章｜接手紀錄（2026-11-06）

## 決策
使用者不滿意 v1.1-full21 的白底、固定主圖加四個說明區塊；希望每頁都像全彩宣傳 DM，吉祥物在場景中直接帶讀者理解內容，搭配漫畫式對話框。參考來自使用者提供的台灣環境部宣傳素材，**只參考視覺概念，不挪用其角色/商標**。

首次 DM 圖像誤用綠色圓形吉祥物。後來使用者提供兩張正式角色圖，命名 **拜爾 Bio**，性格是熱心助人的知識解說機器人。已重新生成 P01、P02、P03，使用者回覆「太讚了!這就是我要的」，因此這三頁的視覺方向確認，可作為後續 17 頁的風格依據。

## 新版第一章三頁內容
- **P01** 使用本手冊：四步驟「先觀察 → 記錄 → 比對 → 尋求協助」，拜爾翻手冊、量測、記錄、比較與通報。安全核心：資料不足不能當正常。
- **P02** 健康快篩：拜爾拿放大鏡，圍繞完整十項表格；危險時先撤離、不等填完。正式版需保留原 JSON 的完整十題，且支援正常／異常／未知／不適用。
- **P03** 系統流程：拜爾指示進料 → 厭氧槽 → 沼氣處理／儲氣／發電，以及沼渣沼液後續核准處理。順序是功能概念、非施工圖。
- 原稿參考：`content/handbook.json`；原版 PDF 及 HTML 仍在 `output/v1.1-full21/`。
- 本輪用戶確認的是**設計方向**，並非每一條技術文字、每張箭頭或安全規範的正式批准。
