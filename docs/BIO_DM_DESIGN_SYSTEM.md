# 沼氣場健康檢查手冊｜拜爾（Bio）全彩 DM 視覺設計規範

> 狀態：使用者已確認 **P01–P03 的全彩宣導 DM 視覺方向**（2026-11-06）。本規範是下一版工作的依據；舊版 v1/v1.1 全部保留。圖像成品需另行納入 Git 並校稿，不能因本文件存在就宣稱發布完成。

## 1. 內容定位
- 主讀者：畜牧場業者、操作人員、無環工背景的案場管理者。
- 一本由熱心助人的沼氣小機器人 **拜爾 Bio** 全程帶領的圖解手冊。
- **封面＋20 張 A4 直式獨立 DM**；每一頁都是完整、醒目、有教學目的的海報，而非「上方一張照片、下方制式四欄文字」。
- 風格：活潑、色彩飽滿、親民但不幼稚；大型多色標題、圓角資訊區、漫畫對話框、場景插畫、清楚箭頭、強對比字色。
- 使用者提供的環境部宣傳 DM 僅作**視覺節奏與吉祥物互動概念參考**。不得使用其吉祥物「綠寶」取代拜爾，也不得直接複製圖案、文字、商標或版面。

## 2. 吉祥物身份（最重要）
- 名稱固定為 **拜爾（Bio）**，性格是熱心、可靠、耐心，用容易懂的說法向大眾介紹沼氣知識；不是綠色圓球生物。
- 唯一身份參考圖：使用者原始上傳的 `mascot-character-sheet-v0.1.png` 和 `mascot-pose-sheet-v0.1.png`。
- 外觀必須保留：黃色安全帽及綠葉徽記、深灰黑面罩、亮綠數位眼睛、綠色機器身軀、胸前儀表與葉片徽章、圓潤四肢與大鞋。
- 每頁依內容重新設計互動動作，例如翻手冊、指流程設備、拿放大鏡巡檢、填寫紀錄、指向安全路線等。不可只把相同貼圖放在角落。
- 可以多次出現同一角色的連續動作，但維持五官、頭身比例、胸章與安全帽一致。危險頁改用嚴肅提醒表情。
- 不要在生圖時模仿或替換成其他機器人/綠寶。

## 3. 每頁敘事結構（可依內容調整）
1. 頁首：沼氣場健康檢查手冊 / 章節 / Pxx。
2. 大標：問題式標題，易讀、醒目，適量雙色或描邊，不使用太多小字。
3. 拜爾主場景：角色與**本頁的真實知識物件直接互動**，說一句口語短句（漫畫對話框），帶入主題。
4. 核心教學：流程、設備剖面、比較、診斷樹或清單等，依頁面任務客製，不硬套同一模板。
5. 行動資訊：現場可觀察什麼／先做什麼／何時交給專業人員，使用可掃讀小區塊。
6. 安全界線：紅／黃警示設計與明確行動用語；危險情境以撤離、通報優先。
- 文字需先由 `content/handbook.json` 擷取，以現有版本語意為基礎，必要改寫須經技術校稿；插圖不代表施工圖、原廠設定或 SOP。
- 現場重點的文字、重要數值、表格、警語、箭頭和標籤**優先後製為可編輯文字／向量圖層**。AI 直接產生的中文字可能有錯、漏或筆畫不正確，不能跳過校對。

## 4. 排版與印製
- 原稿 A4 直式，原圖至少保留獨立 PNG，另有排版來源（HTML/CSS、SVG 圖層或其他可編輯結構）。
- 每頁可採獨立配色、圖文布局、對話框尺寸；統一角色、文字字體系統、標題語氣、安全標示、章節色與頁碼。
- 優先保證 100% 印刷大小字可讀，繁體中文正確、對比足夠；表格必須能實際填寫。
- 保留合理安全留白與裁切安全區；不得以色彩取代「正常／異常／未知」等明確標示。
- 完整出版檔另從來源輸出 PDF；不可只把概念圖拼成正式可編輯文件。

## 5. 分頁製作策略
- 每次先讀 JSON 內容與設計圖後設計**本頁特有的重點資訊視覺**，不是統一的「大插畫 + 2×2 文字」。
- P01 導讀：四步驟故事；P02 快篩：可勾選十項巡檢；P03 流程：進料、厭氧消化、沼氣處理/發電、沼渣沼液路徑；其他頁依 `docs/BIO_DM_PAGE_PLAN.md`。
- 角色主圖應跟設備或表格直接互動，對話框要短、白話、與畫面相呼應。
- 工業設備需可辨識且流程技術合理。不得把充滿色彩的插畫當成技術審查通過。
