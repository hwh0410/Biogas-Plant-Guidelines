# 第三章｜沼氣處理與安全（拜爾 Bio DM 正文）

> **文件狀態**：內容編輯定稿，供 P09–P12 DM 排版使用；非工程／工安簽核，也不是現場操作 SOP。機組及儲氣設備允收值依原廠規格、設計與案場歷史資料。此文由 `content/bio-dm/chapter03.json` 維護，請勿修改歷史 `content/handbook.json` 或 v1.1-full21 輸出。

## P09｜儲氣袋為什麼會鼓起來？

**一眼記住**：儲氣設備協助穩定供氣；外觀不等於實際儲氣量。

**拜爾說**：「外膜看起來鼓鼓的，不代表裡面的沼氣一定很多！」

**設備原理**：厭氧槽產氣與發電機用氣不一定同步。單膜式通常由主要氣密膜包覆沼氣；空氣支撐型雙膜則由內膜形成儲氣空間，外膜透過支撐空氣維持形狀。各型式仍應依設備設計與儀表判讀。

**先看哪裡**：安全距離觀察膜體、固定件及既有壓力或容量指示；比對同期間產氣、用氣、機組負載及警報紀錄。

**可能原因**：用氣量超過產氣量、膜體與固定件損傷、支撐空氣或調壓系統異常，都可能改變可用儲氣或外觀。

**可以先做什麼**：記下發生時間、天候和讀值，與本場正常紀錄比較，並在安全位置通報。

**何時找人**：壓力警報、異常變形、固定件受損或疑似漏氣；檢漏與維修由專業人員處理。

**安全界線**：不得踩踏、攀爬、按壓、加重物、調整保護閥或自行修補儲氣袋。

## P10｜沼氣為什麼需要脫硫？

**一眼記住**：硫化氫（H₂S）有毒且會造成設備腐蝕；要看處理後是否符合使用設備條件。

**拜爾說**：「脫硫不是只看設備有沒有開，還要看前後端的硫化氫紀錄！」

**設備原理——三大類、五種方式**：
- **固體材料**：活性碳（吸附／表面反應）、氧化鐵（含鐵材料與 H₂S 反應）。
- **液體洗滌**：水洗（吸收）、鹼水洗（吸收與化學反應）。
- **微生物處理**：生物脫硫（硫氧化微生物將硫化物轉為元素硫或硫酸鹽）。

**先看哪裡**：既有密閉量測系統的前後端 H₂S、流量、壓差、警報及耗材或循環液紀錄。

**可能原因**：入口負荷增加、材料逐步失效、洗滌或生物系統異常、堵塞或量測問題。

**可以先做什麼**：記錄前後端數值與維護時間，比對原廠允收條件；交由授權人員判讀。

**何時找人**：出口 H₂S 持續偏高、壓差異常、警報或升溫；由專業人員採樣、開塔、換料與處置廢棄物。

**安全界線**：不能用嗅覺辨識 H₂S；不得自行開孔、開塔或切旁通。使用後含硫反應材可能涉及氧化放熱風險。

**編輯註**：109 年手冊的 200 ppm、耗材單價及更換頻率是特定時期或案例資料，**不列入此 DM 的通用門檻**。

## P11｜沼氣管線為什麼會積水？

**一眼記住**：含水沼氣遇冷會凝結；積水可能增加輸送阻力並影響供氣。

**拜爾說**：「熱熱的沼氣遇到比較冷的管線，水氣就可能凝成水滴喔！」

**設備原理**：沼氣含有水氣，降溫時部分水氣凝結。常見方式包括**冷卻除濕**（降溫→凝結→收集）與**固體吸附除濕**（矽膠或活性氧化鋁等乾燥材料）。管線低點的冷凝水須依工程設計以密閉裝置管理。

**先看哪裡**：既有管線前後壓力、排水器指示、設備警報；安全位置的低點與支架外觀。

**可能原因**：管線降溫、低點積水、排水器異常或管路堵塞；但供氣不穩不一定都是積水。

**可以先做什麼**：記錄時間、天候、壓力和維護狀況，只觀察既有儀表，不自行排放。

**何時找人**：排水器警報、壓力異常、反覆供氣中斷或支架受損；由專業人員清堵、檢漏及維護。

**安全界線**：不得鬆開接頭、打開排水閥、拆管、用火測漏或臨時改管。

## P12｜遇到沼氣危險，該怎麼辦？

**一眼記住**：遇到警報、疑似洩漏或人員不適，先離開危險區，到安全地點通報。

**拜爾說**：「先離開、再通報！不要為了找原因冒險留下來！」

**三種危害**：
- **甲烷 CH₄**：洩漏後與空氣形成可燃混合氣，遇點火源可能燃燒或爆炸。
- **硫化氫 H₂S**：有毒，高濃度可能快速造成嚴重傷害；不能靠氣味判斷。
- **缺氧**：槽池、坑井與局限空間可能缺氧，不能靠外觀判斷。

**緊急應變四步驟**：
1. **辨識危險**：氣體警報、疑似外洩、火煙、電氣異常或身體不適。
2. **遠離現場**：停止接近，沿核定安全路線撤離，不進入低窪及密閉空間。
3. **安全地點通報**：依緊急程序聯絡負責人；有人倒地、火災或其他急迫危害時撥打 119。
4. **等待專業處置**：不自行返回、不冒險救援；由受訓且具合適裝備的人員偵測、隔離、救援及確認復歸。

**安全界線**：警報消失不代表安全；未經確認不得返回。不得進入局限空間貿然救人。
