# 拜爾 Bio × 20 頁 DM 版型任務地圖

> 原 20 頁章節不更動；依 `content/handbook.json` 的內容重新決定每頁主要畫面。以下為視覺提案，非新操作規範。

| 頁次 | 主題 | 建議主視覺：拜爾如何參與 | 關鍵版面形式 |
|---|---|---|---|
| P01 | 如何使用本手冊 | 拿手冊帶著讀者走四站，放大鏡／紀錄板／趨勢表／通報 | 四步驟漫畫資訊卡 |
| P02 | 我的沼氣場健康嗎？ | 拿放大鏡和巡檢板，引導填寫十項狀態 | **十項完整快篩表**，正常／異常／未知／不適用 |
| P03 | 沼氣從哪裡來？ | 指著全場縮小模型解說物料、氣體、電力及出料 | 完整流程主圖＋四個對應判讀框 |
| P04 | 進料與前處理 | 與進料車、泵浦或分離機互動，查看料源與紀錄 | 進料路徑＋變更檢查 |
| P05 | 厭氧槽是否正常？ | 在槽外看儀表與趨勢，旁有正常/異常概念剖面 | 同槽型比較＋讀值趨勢 |
| P06 | 為什麼沼氣變少？ | 拿放大鏡追查產氣表和氣路，示範分支選擇 | 故障判斷流程樹 |
| P07 | 沼氣品質不穩定 | 指出甲烷與硫化氫量測讀值、量測位置 | 氣質比較＋量測提醒 |
| P08 | 沼渣沼液排得順嗎 | 從安全距離查看出料、接收槽和泵浦 | 出料路徑＋阻塞線索 |
| P09 | 儲氣袋健康嗎 | 觀察不同型式的儲氣袋、壓力儀表 | 形式比較＋正常與異常提醒 |
| P10 | 脫硫設備有在工作嗎 | 比較處理前後 H₂S 記錄，不自行開塔 | 前後端量測示意 |
| P11 | 管線與脫水設備 | 指管線低點和密閉排水器 | 氣路與冷凝水路徑 |
| P12 | 遇到危險先做什麼 | 嚴肅指引人員撤離至安全區 | 大型撤離路線與禁止事項 |
| P13 | 發電機啟動前 | 拿授權檢查表核對機組外觀與控制訊息 | 啟動前安全核對 |
| P14 | 發電機發不動 | 記下首次警報與反應，不反覆重試 | 警報情境對比 |
| P15 | 發電機一直停 | 指警示燈與停機前趨勢 | 首次警報與停機原因 |
| P16 | 有發電卻發得不多 | 同時看發電時數、功率、度數 | 三項指標比較＋公式 |
| P17 | 日常保養 | 拿工作單和保養時程表 | 保養紀錄時間線 |
| P18 | 異常快速對照 | 在索引告示牌引導讀者找頁碼 | 快速症狀導航 |
| P19 | 每日/每週巡檢表 | 小比例拜爾協助填寫，不搶表格空間 | 可列印可填寫表格 |
| P20 | 需要專家協助時 | 在安全地點打電話，提示必備資訊 | 通報卡與聯絡資訊 |

## 第一章已確認的方向
- 第一輪 DM 概念曾產生綠色圓球角色，不符官方吉祥物。
- 使用者 2026-11-06 提供兩張角色設定圖並正式取名 **拜爾（Bio）**。
- 使用者已明確肯定第二輪 P01–P03 全彩視覺方向，後續要以這組為美術語言基準。
- **注意：概念生圖的繁體中文和圖文資訊可能有漏字、錯字或與 JSON 不一致，正式出版仍需文字分層重排與校對。**
- P02 正式版須恢復「不適用」欄位或其他清楚可記錄方式；P03 須避免將所有案場的儲氣、脫硫、脫水順序畫成唯一標準。
