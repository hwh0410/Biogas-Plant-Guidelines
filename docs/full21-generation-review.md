# 封面＋20 頁獨立圖像生成紀錄

## 本輪範圍
使用者授權依全書需求直接生成 20 張圖片並外加封面。本輪執行 21 次內建 image_gen.imagegen，得到 21 張不同的原生 PNG，未重用前輪四張圖，也未以裁切吉祥物貼圖。每次呼叫均帶入兩張官方 PNG。

## 交付層次
- assets/illustrations/v1.1-full21/：21 張純插畫原圖、21 份實際提示詞、原始輸出位置及 SHA-256 manifest。
- output/v1.1-full21/pages/：封面＋P01–P20 的完整中文頁面 PNG，由同來源 PDF 經 Poppler 渲染為 A4 200 dpi。
- output/v1.1-full21/Biogas-Plant-v1.1-full21.pdf：完整可搜尋文字 PDF，原文與所有表格／公式皆保留。
- output/v1.1-full21/handbook.html：離線網頁，圖片內嵌；390/768 px 直向閱讀，表格區可橫向捲動。

## 圖像及內容審查
- 逐張查看 21 張生成圖：角色維持黃葉片安全帽、暗色面罩、亮綠數位眼睛、儀表／葉片胸章與短圓潤身形；姿態依頁面改變。未使用原圖裁切。
- P05 槽內展示是概念剖面，不表示允許開槽；原文完整保留不可開蓋與不可入槽警語。
- P09 顯示雙膜概念內外差異，不能用外膜外觀診斷儲氣量。儀表色帶不代表通用允收區。
- P10 為乾式吸附範例，圖中曲線無實測值；前後量測紀錄由中文圖層說明，不能據圖施工。
- P11 管內水為教育插圖局部，實體管線封閉，未指引開管或排放。
- P12 嚴肅角色引導離開；集合點與路線圖案為情境示意，實際路線由案場核定。
- P13 圖中核對記號為敘事，不能視為已取得啟動或安全許可；原文授權界線保留。
- P20 通訊情境安排於安全區，非危險區使用手機。
- 設備接管、監測點、儀表曲線及設備型式仍需專業審查；本版不是操作 SOP 或施工圖。
- 主圖儀表與紙張上未採用生成的精確數值；所有重要中文、門檻、表單及公式使用原始 JSON 後製。

## 自動驗證
- 21 個頁面、21 張原圖、21 張完整頁面 PNG、21 頁 A4 PDF。
- 逐頁核對標題、關鍵句、所有內文項目、完整警語、提示、來源與相關頁；核對表格、空白表單與容量因數公式。

- 390/768 px 沒有整個網頁的橫向溢出；表格保留獨立捲動區。
- 前版 d2f825e 的既有內容／網頁／產物／QA 逐位元比對不變。

## 清晰度與出版狀態
原生圖像解析度見 manifest；頁面 PNG 為 A4 200 dpi，不宣稱 300 dpi 原生主圖。PDF 與網頁的顯示副本採高品質 JPEG 編碼以降低檔案體積，原生 PNG 原圖不變。所有字型與版面結果以 QA 實測為準。
